# ML Engineer Roadmap Dashboard

Interactive 6-month roadmap to become a job-ready ML engineer, built with Streamlit.

## Setup & Run

```bash
# 1. Install dependencies
pip install -r requirements.txt

# 2. Run the app
streamlit run app.py
```

The app opens at **http://localhost:8501**

## Features

- **6 pages**: Overview, Beginner, Intermediate, Advanced, Projects, Interview Prep
- **Checkbox tracking** — tick topics as you complete them, progress bars update live
- **Every topic** has exactly one curated resource linked beside it
- **6 portfolio projects** with clear success criteria
- **Interview prep** — mental models + top questions
- Progress persists within your session

## Deploy for free

**Streamlit Community Cloud** (easiest):
1. Push this folder to a GitHub repo
2. Go to share.streamlit.io → New app → pick your repo → `app.py`
3. Done — shareable public URL in ~2 minutes

**Railway / Render / Fly.io**: also work, use the requirements.txt as-is.
